# ADR 015: Explicit language requests and Phase 4 completion decisions

- **Status:** Accepted
- **Date:** 2026-10-25

## Context
The Phase 4 audit (see `docs/PROGRESS.md`) found the agent core, education pack, locale packs, guardrails and Stage C gates in place. Open items: a customer who explicitly asks for a language could still be overridden by detection; the education pack had no budget slot; integer slots accepted at most three digits; the evaluation had no slot-accuracy or tool-round metrics and no cases for the Stage C gates, corrections or multi-slot messages.

## Decisions
- **Explicit request outranks detection.** Each `LocalePack` lists imperative `languageRequestPhrases` that ask to be answered in that locale, in any supported language ("rus tilida yozing", "напишите на английском", "reply in Russian"). Bare language names are excluded on purpose (an "English course" is a subject). `requestedLocale` returns a locale only when exactly one supported locale matches. A request pins the reply locale for the turn and, replayed from the history, for later turns until another request; a pinned locale satisfies the language gate's evidence rule. The wording is beta, not native-reviewed, and false negatives fall back to normal detection. The core holds no wording: the phrases live in the packs.
- **Budget slot.** The education pack gains an optional `budget` integer slot (UZS, qualifying only, no search filter, never shown as a price). Integer slots accept up to 12 digits with space-grouped digits; pack min/max still apply (student age stays 3–99).
- **Evaluation.** Cases may carry `history`, expect a `safety` outcome and an exact provider-call count. Reports add slot extraction accuracy and mean tool rounds next to the existing tool-call validity, structured-output validity, hard-fact violations, language/script match and cost. Gate cases are generated by `eval/generate_gate_cases.py` for all four locales. All of these run on scripted model output only.

## Not done (boundary)
- Tracking which offers were shown and writing `Quote` rows need the lead/booking model: Phase 5. Repeated-question detection ("STUCK") is a Phase 5 handover trigger.
- No live model evaluation, no native-speaker review, no operator notification.
