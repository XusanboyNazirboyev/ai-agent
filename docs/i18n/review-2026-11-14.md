## Three least-certain strings in uz-Latn (with suggested alternative)

1. `channels.desc.telegram` — "Telegram botingiz orqali mijozlar bilan suhbat bo‘ladi. Suhbatni operator guruhda yoki shu inbox’da olib bora oladi." — "olib bora oladi" is clunky; alternative: "Suhbatni operator guruhida yoki shu inbox’da qabul qila oladi."
2. `knowledge.notConfigured` — "Texnik administrator server sozlamalarida bilimlar qidiruvini yoqishi kerak (...) va API ni qayta ishga tushirishi kerak." — passive "kerak" twice; alternative: "Texnik administrator server sozlamalarida bilimlar qidiruvini yoqadi va API ni qayta ishga tushiradi."
3. `sheet.boundOther` — "Yordamchi narxlar uchun hali ham «{name}» dan foydalanadi. Buni Sozlamalar, Tashqi CRM bo‘limida o‘zgartiring." — "{name}" placeholder could be a CRM name or sheet name; alternative: "Yordamchi hali ham «{name}» manbasidan narx oladi. Uni Sozlamalar > Tashqi CRM da o‘zgartiring."
