### 2. Placeholder match (ICU `{...}` / `{name, plural, ...}`)

```
node -e "...compare placeholder multisets of ru vs en per key..."   # see /tmp/audit-scan.js
```

Output summary:
```
PLACEHOLDER_MISMATCHES_ru_vs_en: 23
PLACEHOLDER_MISMATCHES_uz_vs_en: 23
```

All 23 are ICU plural-form differences: English uses only `one`/`other`, while
Russian correctly adds `few` and `many` (e.g. `# минут / # минуты / # минут`).
These are **not bugs** — Russian grammar requires `one`/`few`/`many`/`other`.
Every mismatched key keeps the same argument names (`{count}`, `{minutes}`, `{date}`,
`{name}`, `{fields}`, `{line}`, `{role}`, `{used}`, `{max}`, `{start}`, `{end}`,
`{days}`, `{value}`, `{total}`, `{part}`, `{peakDay}`, `{peak}`, `{message}`,
`{email}`, `{filter}`, `{stage}`).
