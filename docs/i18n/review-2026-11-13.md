## Translation inconsistencies found

The same English term is translated differently in two places:

1. **"AI staging"** — `pipelines.aiStaging` = "Постановка ИИ" / "AI bosqichlash"; `leads.aiBlock` = "Этапы от ИИ" / "AI bosqichlari" (ru/uz-Latn differ from pipelines keys; `toast.aiStagingUpdated` matches pipelines). Keys: `pipelines.aiStaging`, `leads.aiBlock`, `toast.aiStagingUpdated`.

2. **"stage" as a verb/noun** — `pipelines.stageKind` = "Тип этапа" / "Bosqich turi"; `leads.stageProgress` = "Этап" / "Bosqich"; `leads.moveToStage` (existing) = "Этап воронки" / "Voronka bosqichi". Reasonably consistent, but `pipelines.stageKind.WON/LOST` use "Won/Lost" while `leads.stage.WON/LOST` also use "Won/Lost" — consistent across both.

No `{{}}`/HTML issues. ICU plural in `leads.ageLabel` uses `one`/`other` for ru but only `one`/`other` for uz-Latn (uz needs `few`/`many` for correct plural forms — ru has them, uz-Latn currently only has `one`/`other`).
