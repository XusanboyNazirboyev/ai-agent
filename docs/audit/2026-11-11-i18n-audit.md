## 1. Method

Deterministic scans (run in the worktree; see task report for exact commands):

1. **Catalog parity (D22):** compared key sets of `en/ru/uz-Latn` (counts and set differences). Existing `apps/web/src/i18n/catalog.test.ts` also enforces: exact key parity with English, non-empty values, identical ICU argument names, valid ICU messages, dynamic key families, and required error/rule keys.
2. **Hardcoded JSX text / user-visible attributes:** (a) the `findHardcodedText` heuristic used by `catalog.test.ts` over all non-test `.tsx` files except `app/layout.tsx`; (b) literal `aria-label`, `placeholder`, `title`, `alt` attributes (`"..."`, `'...'`, and `{ '...' }`/`{ "..." }` forms) in non-test source; (c) `toast('...')` calls with a literal (non-`t(...)`) argument.
3. **Metadata / document titles:** `export const metadata` `title`/`description` string literals in `app/**` pages/layouts.
4. **Unused-key candidates:** catalog keys whose exact string does not appear anywhere in `apps/web/src` non-test source (rough). Many matches are false positives for runtime-composed keys (e.g. `errors.${code}`, `state.${value}`, `handover.reason.*` families) that `catalog.test.ts` already validates.
5. **Exclusions (not reported as UI strings):** `data-testid`, class names, URLs, log/console messages, non-UI constants, and test files.

## 5. Unused-key candidates (reported, not removed)

Naive check: **277** of 887 English catalog keys have no exact string occurrence anywhere in `apps/web/src` non-test source. This is **not** a definitive unused list:

- **Dynamic families (expected):** many are composed at runtime and are already required by `catalog.test.ts` (e.g. `errors.*` via `errors.${code}` / `errorKey`, `state.*`, `author.*`, `delivery.*`, `score.*`, `leadStatus.*`, `leadStages.*`/`leads.stage.*`, `role.*`, `scope.*`, `canned.*`, `connection.*`, `actionStatus.*`, `locale.*`, `botMode*`, `channelStatus/agentMode`, `importProblem.*`, `knowledgeTab.*`, `nav.*`, `handover.reason/intent/language.*`, `console.*`, `platformRole/tenantStatus/subscriptionStatus/accessState/paymentStatus/paymentProvider`, `notify.subscription.*`, `theme/permission`, etc.). Absence of a literal key string in source is expected for these.
- **Potentially unused (needs confirmation):** a subset may be unused after refactors, but automated proof requires data-flow/key-family awareness; removing keys without certainty can break runtime `t(...)` calls. No key was deleted in this task.

Representative dynamic-family examples flagged by the naive scan (all still covered by `catalog.test.ts` families/gates or by runtime composition): `errors.*` (`UNAUTHENTICATED`, `INVALID_CREDENTIALS`, …), `state.*`, `role.*`, `locale.{en,ru,uz-Latn}`, `handover.reason.*`, `canned.*`, `notify.subscription.*`.
