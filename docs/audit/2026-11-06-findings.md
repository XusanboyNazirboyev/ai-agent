# AgentCore audit findings — 2026-11-06

Commit under review for every row: `18decb294330b0a1ea386d827b1a1d8c2043b0c7`. Severity is practical impact, not proof of exploitability. Suspected/needs-runtime items are not confirmed vulnerabilities.

## Executive summary and threat model
- Confirmed behavior gaps: waiting pagination is not globally longest-wait-first; views stop at 500 oldest messages; concurrent login failures can lose increments; established SSE streams survive logout; fallback titles bypass the display gate; late reply success can erase a new conversation's draft; knowledge-only packs cannot pass the current catalog gate.
- Threat model: assets are tenant conversations/contact data, credentials, CRM facts, knowledge, and confirmed business actions. Boundaries are browser session/proxy → API, webhook → durable event/outbox → queue, CRM/knowledge → prompt, model proposal → server-authorized tool, and connector egress. Relevant threats are BOLA, stale-session access, login abuse, SSRF/replay, prompt injection, secret disclosure, and duplicate/uncertain external writes.
- Static review found existing tenant-scoping, CSRF/origin, webhook-signature, connector egress/DNS, tool-authorization, and fact-provenance controls. The review did not prove all endpoints safe. OAuth is not implemented; no OAuth state/code replay path was assessed. No additional confirmed exploit was demonstrated in the reviewed connector/webhook surfaces.

## Remediation status (working tree, 2026-11-06)
- **AUD-03:** `SessionService.setPassword` now updates credentials and revokes active sessions for that tenant/operator in one transaction. Regression verifies the prior session is rejected and an unrelated tenant's session remains valid.
- **AUD-05:** failed-attempt updates use a conditional atomic database update; expired lock windows restart at one. Successful-login state is compared before session creation so a concurrent lock or password change is re-read. Integration regressions cover parallel failures and these races.
- **AUD-15:** open SSE streams revalidate session revocation, expiry, idle expiry, and operator activity before reading/sending events, failing closed. Integration regression exercises logout and the other invalidation cases.
- Targeted API integration (60 tests across Web Inbox/session/SSE and Instagram flow), API policy/startup unit (24), API typecheck/lint/build passed. These changes remain uncommitted in the worktree; no schema migration, push, or deploy was performed. Findings above describe the audited HEAD, not a claim that the branch has been released.
