# Phase 6A evidence — Web Operator Inbox (2026-10-24)

Branch `phase6a/web-operator-inbox`; last tested commit is stated in PROGRESS. Environment: PostgreSQL + pgvector (`agentcore_test`), Redis, Node 24 in CI (Node 26 locally), Chromium. No Telegram, tunnel, webhook or real Operator record was used; all operators are fake fixtures in `agentcore_test`.

| Roadmap "Done when" | Evidence |
|---|---|
| Operator completes see → take over → reply → return in the browser | `e2e/operator-flow.spec.ts` (also close, note, lead status, search, quick reply, SLA banner) |
| Two browsers stay in sync in real time | `e2e/realtime.spec.ts`: take-over, new message, new handover appear without reload; take-over race has exactly one winner |
| SSE reconnect / recovery | blocked stream retried and caught up over REST; server-closed stream reconnects; refused stream falls back to polling and returns to live; `Last-Event-ID` replays only newer events in order |
| Tenant A cannot access tenant B | `e2e/isolation.spec.ts` (API read, every list scope, search by name and text, commands incl. reply, pasted URL, SSE stream) + `webinbox.integration.spec.ts` (service level) |
| Viewer cannot act | UI hides actions; direct POST returns 403 and state is unchanged |
| Cookie auth, CSRF, Origin, logout | `e2e/auth.spec.ts` (httpOnly + SameSite=Strict, CSRF cookie readable, missing/wrong token 403, foreign Origin 403, logout kills the server session) |
| No hardcoded UI strings, key parity | `src/i18n/catalog.test.ts`: identical keys and ICU arguments in uz-Latn, ru, en; plurals; heuristic scan of JSX text and literal aria/placeholder/title; runs in `pnpm test:unit` (CI) |
| e2e green in CI | CI job `quality` runs `pnpm test:e2e` after build |

Other checks: lint, typecheck, format, build (API + web), unit, integration (incl. app startup), migration drift, coverage. Plain-text rendering of customer HTML and the security header set are asserted in `e2e/ui.spec.ts`.

Limits: see "Deferred" in ADR 020. UI translations for ru and uz-Latn are not native-reviewed (D18: beta). The hardcoded-text scan is a heuristic, not a parser.
